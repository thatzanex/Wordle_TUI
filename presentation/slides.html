01 · Überblick

Was ist WordleApp?

WordleApp ist ein vollständiger Klon des Spiels Wordle, gebaut als Terminal User Interface in C# / .NET 8. Läuft komplett in der Konsole — dank Spectre.Console sieht es trotzdem poliert aus.

  • Figlet-Banner, abgerundete Panels, farbige Kacheln, Ladeanimation
  • Zwei Sprachen (Deutsch/Englisch), beliebig erweiterbar per JSON
  • Drei Schwierigkeitsgrade mit eigenen Regeln & Punktemultiplikatoren
  • Externe Wortquelle über eine Zufallswort-API + optionale Wörterbuch-Validierung
  • Persistente Einstellungen & Bestenliste in JSON-Dateien
  • Adaptives Layout, das sich live an die Terminalgröße anpasst

05 · Kernlogik

WordEvaluator — der Doppelbuchstaben-Fall

Enthält das Zielwort einen Buchstaben nur einmal, der Guess ihn aber mehrfach, darf nur eine Stelle als „vorhanden“ markiert werden. Lösung: ein Zwei-Durchlauf-Algorithmus.

  • Pass 1 — alle exakten Treffer (grün) markieren & Zielbuchstaben „verbrauchen“
  • Pass 2 — für jeden Rest: kommt der Buchstabe woanders im noch nicht verbrauchten Zielwort vor? → gelb, sonst grau

Nur eine der drei S-Positionen wird als Treffer gewertet — bestimmt durch den Algorithmus, nicht durch Lesereihenfolge.

06 · Scoring

Punkteberechnung

  • Grundpunkte fürs Gewinnen — 1000 (nur bei Sieg)
  • Bonus für ungenutzte Versuche — 150 pro übrigem Versuch
  • Geschwindigkeitsbonus — linear von 600 auf 0 über die ersten 120s
SchwierigkeitMultiplikator
Easy0,75×
Normal1,0×
Hard1,5×

Eine verlorene Runde ist immer 0 Punkte, unabhängig von investierter Zeit.

07 · Externe Anbindung

DictionaryApiService

Zwei HTTP-Aufrufe, behandelt als unzuverlässig und langsam: eine Random-Word-API für Zielwörter (im Hintergrund vorgeladen) und eine Dictionary-API zur Validierung.

  • Eigene, enge Timeouts pro Anfrage
  • „Fails open“ — nur ein explizites 404 lehnt einen Guess ab; Timeouts/Fehler lassen ihn durch
  • Nach 2 Fehlschlägen wird die Validierung für die Sitzung deaktiviert
  • Antworten werden gecacht — kein Wort wird zweimal abgefragt
08 · Rendering

Adaptive Darstellung

FrontendRenderer.cs — die einzige Klasse, die Spectre.Console direkt nutzt (>1100 Zeilen).

  • Adaptive Kachelgröße — 6 Qualitätsstufen, größtmögliche Kachel wird gewählt
  • Live-Neuberechnung bei Fenstergrößenänderung (Resize-Polling alle 40ms)
  • „Shimmer“-Animation — graue Welle über die aktive Zeile während der Wörterbuch-Prüfung
  • Fallback ohne Farbunterstützung — Klammer-Notation [[W]] / (O) / X
  • Markup-Escaping — Spielernamen werden immer escaped

10 · Ausblick

Bekannte Grenzen

  • Keine automatisierten Tests (Schlüsselmethoden sind aber bewusst virtual und damit testbar designt)
  • Kein Multiplayer, keine Online-Bestenliste — rein lokal
  • Kein täglicher Modus — jedes Zielwort ist zufällig
  • Reine Flatfile-Persistenz (JSON) statt Datenbank — für den Anwendungsfall ausreichend
